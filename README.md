# 🏪 우리 반 앱 진열장

바이브코딩으로 만든 수업 앱을 한곳에 모아 **깃허브(GitHub Pages)** 로 문을 여는 진열장입니다.
2026 광남초 「AI와 바이브코딩을 활용한 수업·평가 디지털 도구 만들기」 2차시 실습 키트.

## 들어 있는 파일

| 파일 | 하는 일 | 고치나요? |
|---|---|---|
| `index.html` | 진열장 첫 화면 | ✏️ 맨 위 두 칸(우리 반 소개, 앱 목록)만 |
| `banner.jpg` | 맨 위 큰 그림 | 같은 이름으로 다시 올리면 바뀜 |
| `character.png` | 우리 반 캐릭터 | 같은 이름으로 다시 올리면 바뀜 |
| `weather.html` | ⑤ 공용 API 예시 — 우리 학교 기상 관측소 | ✏️ 학교 이름·좌표 한 줄 |
| `README.md` | 이 안내문 | 아니요 |

## 문 여는 순서 (10분)

1. **새 저장소** — 깃허브 오른쪽 위 `+` → `New repository` → 이름 `myclass-apps` → **Public** → `Create repository`
2. **파일 올리기** — `uploading an existing file` (또는 `Add file` → `Upload files`) → 압축을 푼 폴더 **안의 파일들**을 끌어다 놓기 → `Commit changes`
3. **간판 켜기** — `Settings` → 왼쪽 `Pages` → Branch: `main` / `(root)` → `Save`
4. **주소 받기** — 1~2분 뒤 `https://내아이디.github.io/myclass-apps/` 가 열려요 → 패들렛에 올리기

## 앱 더하기

`index.html` → 연필(✏️) → `앱목록` 칸에 한 줄 더 쓰기 → `Commit changes`

```
앱 이름 | 한 줄 설명 | 주소 | 서랍 번호 | 이모지
```

내가 만든 HTML 파일(예: `quiz.html`)은 같은 저장소에 올리고 주소 칸에 파일 이름만 쓰면 됩니다.

## 꼭 지킬 것

- 🔑 **API 키, 비밀번호, 학생 이름·사진은 절대 올리지 않기** — Public 저장소는 누구나 볼 수 있어요.
- 제미나이 API 키는 앱스 스크립트(구글 시트 [설정] 탭) 안에만 둡니다.
